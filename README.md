# Personal Finance & Expense Tracker Dashboard

## Project Overview

Personal Finance & Expense Tracker Dashboard is a full-stack MERN application that helps users manage their personal finances. Users can track income, expenses, budgets, portfolios, and financial reports through a secure and user-friendly dashboard.

---

## Features

### User
- User Registration & Login
- JWT Authentication
- Add, Edit & Delete Transactions
- Budget Management
- Portfolio Management
- Activity Logs
- Profile Management
- Upload Transaction Receipts
- Search & Filter Transactions
- Export Transactions to CSV
- Export Transactions to PDF
- Dashboard with Charts

### Admin
- Admin Dashboard
- Manage Users
- Manage Categories
- View Analytics

### Moderator
- Moderator Dashboard
- Manage Support Tickets
- View Fraud Reports

## Installation

### Clone Repository

```bash
git clone YOUR_GITHUB_LINK
```

### Backend

```bash
cd server
npm install
npm run dev
```

### Frontend

```bash
cd client
npm install
npm run dev
```

---

## Environment Variables

Create a `.env` file inside the server folder.

```env
PORT=5000
MONGO_URI=Your MongoDB Connection String
JWT_SECRET=Your Secret Key
```
